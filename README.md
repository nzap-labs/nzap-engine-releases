# NZAP Engine Releases

Official installer releases and signed auto-update feeds (`latest.json`) for **[NZAP Engine](https://nzap.in)** — one-click AI apps and MCP server on your own Google Colab GPUs.

## Quick Install (CLI & AI Agents)

- **macOS & Linux (`sh` / `bash` / `zsh`)**:
  ```bash
  curl -fsSL https://nzap.in/install.sh | sh
  ```
- **Windows (`PowerShell`)**:
  ```powershell
  irm https://nzap.in/install.ps1 | iex
  ```
- **Windows (`cmd.exe`)**:
  ```cmd
  curl -fsSL https://nzap.in/install.cmd -o "%TEMP%\nzap.cmd" && "%TEMP%\nzap.cmd"
  ```

## Direct Downloads

See the **[Latest Release](https://github.com/nzap-labs/nzap-engine-releases/releases/latest)** for:
